# Cafe Bunny Add-on Editor + Combiner

## เปิดใช้งาน
1. แตกไฟล์ทั้งหมดไว้ในโฟลเดอร์เดียวกัน
2. เปิด `index.html` เพื่อสร้าง Add-on และ `combine.html` เพื่อรวม Add-on
3. ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลด JSZip/FileSaver จาก CDN

## การส่งออก
- หน้า Editor ดาวน์โหลดเป็นไฟล์เดียว `.mcaddon` โดยรวมไอเทมทั้งหมดไว้ในชุดเดียว
- หน้า Combiner รับไฟล์ `.mcaddon` หรือ `.zip` ที่มีโครงสร้างแพ็กจาก Editor นี้ แล้วส่งออกเป็น `.mcaddon`
- ไอคอนหน้า Combiner รองรับ PNG/JPG/JPEG และจะแปลง JPG เป็น PNG ให้
- ตัวตรวจสอบเช็คโครงสร้าง `_BP` / `_RP` และ `manifest.json` แต่ไม่สามารถพิสูจน์ว่าไฟล์ถูกสร้างจากเว็บไซต์นี้จริง หากต้องการยืนยันแหล่งที่มา จำเป็นต้องเพิ่มระบบลงลายเซ็น/รหัสตรวจสอบในไฟล์ที่ส่งออก

## ไฟล์หลัก
- `index.html` — หน้า Editor
- `app.js` — ระบบสร้าง Add-on
- `combine.html` — หน้าเว็บรวม Add-on
- `style.css` — รูปแบบหน้า Editor
- `model-*.js` — ซอร์สโมเดล
- `animation-*.js` — ซอร์สแอนิเมชัน
